# Chapter 2: genetic correlations

This folder documents the LDSC genetic-correlation workflow used in Chapter 2.

- `docs/analysis_workflow.md`: analysis sequence and workflow diagram.
- `docs/methods_examiner_summary.md`: examiner-facing methods description.
- `docs/script_selection_and_review.md`: rationale for selected versions and known limitations.
- `scripts/`: sanitised SLURM templates and consolidated plotting/clustering R script.
- `metadata/`: archived trait annotation and source-file mapping.
- `results/`: archived LDSC result table and significant-count output.
- `figures/`: archived figure outputs from the original analysis.

See the parent repository README for sharing and provenance notes. The archived result table currently contains conflicting repeated records for some trait pairs; do not use it to regenerate final figures until reconciled with the final LDSC outputs/logs.
