# Chapter 2 — Genetic correlations

Contains the LDSC summary-statistic workflow, archived results/metadata, figure-generation scripts and historical analysis fragments. Read `docs/analysis_workflow.md`, `docs/methods_examiner_summary.md` and the repository-level `docs/SCRIPT_AUDIT.md` before interpreting the historical scripts.

The workflow estimates genome-wide genetic correlations; it does not establish causality. Archived results and original figure files are retained as supplied and should be reconciled with final analysis logs where necessary.
