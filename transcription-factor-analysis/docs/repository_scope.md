# Repository scope and release checklist

This repository is the transcription-factor analysis companion to the
genetic-correlation repository. It is intended to preserve an auditable
description of the analysis while keeping large or restricted inputs outside
version control.

Before public release:

- [ ] Confirm the genome assembly and coordinate conventions for each BED-like table.
- [ ] Confirm which annotations are mouse-derived and which are human-derived.
- [ ] Document orthology conversion method/version where applicable.
- [ ] Check permissions for archived PDF figures and gene annotations.
- [ ] Confirm whether SBayesRC results can be redistributed.
- [ ] Add the final thesis citation and any publication DOI.
- [ ] Select and add an appropriate code licence.
- [ ] Test the pipeline in a clean R environment with compatible GWAS and LD inputs.
